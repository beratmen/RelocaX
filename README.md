# 🚚 RelocaX - Professional Moving Services

![React](https://img.shields.io/badge/React-18.3.1-blue)
![Vite](https://img.shields.io/badge/Vite-5.4.8-646CFF)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3.3-7952B3)
![License](https://img.shields.io/badge/License-MIT-green)

Modern, responsive web application for professional moving and relocation services built with React, Vite, and Bootstrap.

## ✨ Features

### 🎨 User Interface
- **Modern Design**: Clean, professional dark-themed interface
- **Fully Responsive**: Optimized for desktop, tablet, and mobile devices
- **Smooth Animations**: Elegant fade-in and slide animations
- **Interactive Components**: Dynamic modals, toasts, and forms

### 📦 Services Showcase
- **6 Service Categories**: Local moving, long-distance, packing, storage, office relocation, and specialty items
- **Visual Cards**: High-quality images with hover effects
- **Detailed Information**: Feature lists and descriptions for each service

### 🎯 Key Sections
1. **Hero Section**: Eye-catching introduction with CTA buttons and statistics
2. **Services**: Comprehensive service offerings with images and features
3. **How It Works**: 4-step process visualization
4. **Testimonials**: Customer reviews with verified badges and trust indicators
5. **Footer**: Newsletter subscription, contact info, and social links

### 🛠️ Functional Features
- **Quote Request Modal**: Multi-step form for getting moving quotes
- **Contact Form**: Easy communication with the company
- **Newsletter Subscription**: Email collection with validation
- **Postcode Search**: Location-based service search
- **Scroll to Top**: Quick navigation button
- **Toast Notifications**: User feedback system

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/beratmen/RelocaX.git
cd RelocaX
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:3000
```
